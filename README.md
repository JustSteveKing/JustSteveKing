## Hey, I'm Steve 👋

Most people know me as JustSteveKing, the API Guy. I write the monthly API Guy column for [php[architect]](https://www.phparch.com/), sit on the [PHP-FIG](https://www.php-fig.org/) Core Committee, and I'm the PHP developer advocate at [SerpApi](https://serpapi.com/).

Most of my own work is the boring HTTP that keeps the people integrating with your API from paging you: the inconsistent errors, the undocumented retry rules, the envelopes nobody tested. It's all PHP, it all follows a published standard where one exists, and it comes from APIs that have survived real traffic.

## What I'm building

- **[sdk-toolbox](https://github.com/JustSteveKing/sdk-toolbox)**, for building PHP SDKs on PSR-18 that read and honour what an API tells them: retries, `Retry-After`, rate limits, idempotency keys, problem details and webhooks.
- **[api-toolbox](https://github.com/JustSteveKing/api-toolbox)**, the other end of the wire: an API that sends those same standards, one RFC at a time.
- **[apiguide.dev](https://apiguide.dev)**, a reference for API design patterns, written for the humans building APIs and the agents calling them.
- **[kit](https://github.com/JustSteveKing/kit)**, an opinionated starter kit for token-based APIs in Laravel, with strong defaults.

If you want to see the toolbox doing real work, [sdk-toolbox-resend](https://github.com/JustSteveKing/sdk-toolbox-resend) rebuilds part of Resend's API on it and compares the result with their official SDK, including the places where theirs is better.
